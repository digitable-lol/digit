# Digitmorf

Digitmorf is Digit's bundled mascot. The desktop renderer uses the production
GLB morph rig; `spritesheet.webp` is the compatible terminal and WebGL-failure
fallback.

The identity is one continuous cyan lowercase-`d` current, asymmetric quantum
attention (one lepton plus a three-quark hadron), and one amber evidence seal.
The same topology resolves into eight semantic forms:

- Core — idle presence
- Cursor — active intent
- Trace — a completed path
- Archivist — reasoning and memory
- Weaver — synthesis and celebration
- Forge — tool execution
- Sentinel — failure and protection
- Lantern — waiting for human input

The 8x9 fallback sheet follows the current Digit/Petdex row order. Its first
six columns are animated poses and its final two columns are transparent
padding. The 3D renderer additionally quantizes attention into 16 directions
and continuously blends between the eight geometry targets.
